# 📅 FlowCal – Smart Calendar with Auto‑Save

A beautiful, responsive, and feature‑rich calendar app built with **vanilla JavaScript**, **HTML5**, and **CSS3**.  
FlowCal helps you manage events with auto‑save to your browser, dark mode, mobile‑friendly bottom sheet, and intuitive navigation.

![FlowCal Preview](https://via.placeholder.com/1200x600/4f46e5/ffffff?text=FlowCal+Calendar+Preview)

---

## ✨ Features

- 📆 **Interactive month grid** – click any date to view or add events.
- 💾 **Auto‑save** – all events persist in `localStorage`; refresh‑proof.
- 🌓 **Light & Dark mode** – toggle theme, saved to your browser.
- 📱 **Fully responsive** – adapts from large desktops to small phones.
- 📱 **Mobile bottom sheet** – sidebar becomes a slide‑up panel on small screens.
- ↔️ **Swipe navigation** – change months with a swipe on touch devices.
- ⌨️ **Keyboard navigation** – arrow keys to move between days, Enter to select.
- ➕ **Add events** – title, optional time, and date.
- 🗑 **Remove events** – delete from the list or via the dedicated remove button.
- ↩️ **Undo delete** – accidental deletions can be restored instantly.
- 🎨 **Modern UI** – smooth animations, rounded corners, and accessible focus states.
- 🧪 **Demo data** – pre‑loaded sample events on first run to get you started.

---

## 🛠 Tech Stack

- **HTML5** – semantic structure
- **CSS3** – custom properties (variables), Flexbox, Grid, animations
- **JavaScript (ES6+)** – vanilla JS, no frameworks or libraries
- **LocalStorage API** – persistent event storage
- **Viewport meta** – `viewport-fit=cover` for notched devices
